By default the list shows items with a stock record at Downtown Office — not “currently has stock,” so a zero-on-hand row still shows (Ultrasound Gel, 0). Show Retired adds retired items (Ultrasound Gel) and Show all tenant items adds Org-managed items not stocked here yet (Paraffin Wax Blocks). Both are drawn on so those rows appear; both default to off. Another location’s own items never show. Category narrows to one category in use; Low stock only keeps rows at or below their threshold (Electrode Pads, Adjusting Table Paper Roll). A retired item is hidden from new Adjustment entry but never deleted, and its history stays.

Reference — Other roles same screen, different grants

Provider, Clinical Staff and Front Desk get the Adjustment popover on every row, either tier, and Item Detail with Edit item, Retire and the threshold edit absent — the row button reads “Details” (ADR-633). Undo shows only on usage rows they logged. Biller gets the list and Item Detail read-only, with no Adjustment action (ADR-490).

Org Admin reads every location through the Location filter and holds catalog write on Org-managed items only: on TheraBand and Paraffin the row reads “Edit”, location-managed rows stay Details. Purchasing Agent (Owner-granted, Phase 3–4) has the same Org-managed catalog write plus Adjustment on Org-managed rows at every location, and no access to location-managed rows (ADR-634).
