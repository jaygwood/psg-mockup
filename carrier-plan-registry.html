Claims, estimates and filing deadlines use the row of the entity their location bills under. This practice has one entity, so the picker isn’t shown above.

Reference — Plan terms as dated versions 2026-10-30, L5

Saving a change to terms already in effect keeps the old terms as an earlier version ending the day before Effective from and starts the new ones that day. Terms that have not started yet, or a change dated the same day as the current version’s start, are corrected in place. Mark reviewed creates no version.
