Reference — permission-denied & states

Permission-denied: this screen’s frame stays visible when reached by a role without access — content replaces with an explicit access-denied message naming Subscription & Billing Console, never a vanished nav entry. Office Admin and Org Admin see this denial for the ENTIRE screen (“Full (Owner only)”) — any role other than Owner or a granted Billing Administrator sees the same full-screen denial. From Phase 3 (absent at Phase 1–2 at any Location count — alignment sweep pass 3, D15), a User holding the billing administrator Role Assignment sees this entire console exactly as Owner does — ADR-301 Decision 4 is a positive allow-list across all five underlying epics, no partial-tab carve-out.

Baseline status (not shown live above): Active, never delinquent — the status pill renders as a plain, non-interactive pill in that case (this file demonstrates the Delinquent, read-only case instead). A trial shows “Trial — 14 days left” and a Users row (reference). Org Admin never opens this console; the storage near-limit warning reaches Org Admin as an Action Center task, acknowledged from its task detail.

Loading: each tab loads independently on activation. Error: a failed fetch on one tab shows inline retry within that tab only; a failed proration/tier-change or Add-On call surfaces as an inline Dialog error, never a toast that could be missed on a financial action.
