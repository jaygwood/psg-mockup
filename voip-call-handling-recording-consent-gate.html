Call initiated

Inbound: the call rings, the patient is resolved via Contact Method match against the caller's number; an unrecognized number lands in an Unknown sender Conversation in the Unified Inbox’s Unrouted View (ADR-689). Outbound: staff selects “Call” in an open Conversation’s thread header, which dials from the Location’s calling number. A Call row is created, direction set accordingly.

Consent-requirement lookup

The Call's location ID (Workflow 16's identical stamping rule used for Message) → that Location's state field → a static, code-defined Call-Recording Consent Requirement table lookup (ADR-243, ADR-156 pattern) → consent required = true or false.

3
Branch — consent required = true (this call)

Only when the Location’s Record calls switch is on (Practice Setup Settings, default Off); with it off, nothing is recorded, no prompt appears and the call shows “Not recorded”. If consent required = false instead, any recording starts immediately and the in-call prompt below never blocks. Here, an in-call consent prompt is shown; no recording starts (or persists) until recording consent obtained = true.
